## Remediation status (2026-10-17)

Remediated: A1, A2, A4, A5, A6, A7, B2, B3 (with the recorded critical-level exception), B4 (verification instructions; signing accepted as not-added), B7, C1. Partially remediated: B1 (bundle hash in stamp; no SBOM). Accepted without code change: A3 (exists-guard already fail-closed).

## Existing protections (verified, for the record)

Lockfile with per-package integrity hashes + `npm ci` in CI; `lint:skills` frontmatter guard; WCAG+APCA audit gate; gold-standard CSS diff (`lint:css`); fail-closed output check in `build.mjs`; deploy rails in `link-skills.mjs` (never deletes real dirs in link mode, prune scoped to links into this repo's `dist/`); generated-prose markers on CSS/primitives (not machine-checked until this plan).
